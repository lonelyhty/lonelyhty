## 我的工作方式

| 原则 | 体现 |
| --- | --- |
| 具体胜过泛泛而谈 | 优先选择能复现、能链接、能测试或能人工验证的问题。 |
| 小而清晰的 diff | 维护者应该能在几分钟内理解补丁。 |
| PR 里写证据 | 在描述中写明单元测试、构建命令、链接验证或手动验证方式。 |
| 公开记录保持准确 | 已合并贡献按 accepted work 展示；open PR 只作为 review 中工作展示。 |
